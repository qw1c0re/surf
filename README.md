# Surf Browser - Современный браузер на Electron

## 📋 Описание

Surf - это полнофункциональный браузер, написанный на Electron с поддержкой:
- Вертикальных вкладок (как Arc Browser)
- AI ассистента с голосовым управлением
- Музыкального плеера
- Красивого интерфейса с Glassmorphism дизайном
- Анимированных обоев
- Сохранения данных и настроек

## 🚀 Установка и запуск

### Предварительные требования
- Node.js (версия 14+)
- npm или yarn

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/qw1c0re/surf.git
cd surf
```

### Шаг 2: Установка зависимостей
```bash
npm install
```

### Шаг 3: Запуск в режиме разработки
```bash
npm start
```

## 🔨 Сборка EXE (Windows)

### Способ 1: Автоматическая сборка
```bash
npm run build:win
```

Этот команда создаст:
- `dist/Surf Browser Setup.exe` - установщик
- `dist/Surf Browser.exe` - портативная версия

### Способ 2: Полная пошаговая инструкция

#### Шаг 1: Установите зависимости
```bash
npm install --save-dev electron-builder
```

#### Шаг 2: Создайте файл icon.ico

1. Скачайте любой конвертер ICO (например, на https://convertio.co/png-ico/)
2. Или создайте простой PNG файл (256x256px) и сохраните как `assets/icon.png`

#### Шаг 3: Запустите сборку
```bash
npm run build:win
```

#### Шаг 4: Найти готовый EXE

После успешной сборки файлы будут в папке `dist/`:
- **Surf Browser Setup.exe** - установщик (рекомендуется для распространения)
- **Surf Browser.exe** - портативная версия (готова к запуску без установки)

### Способ 3: Если команда не работает

```bash
# Установите глобально electron-builder
npm install -g electron-builder

# Очистите cache
rm -rf dist/
rm -rf node_modules/

# Переустановите зависимости
npm install

# Попробуйте сборку снова
electron-builder --win
```

## 🔧 Разработка

### Открыть DevTools
Нажмите кнопку `👨‍💻` в адресной строке или используйте F12 в BrowserView.

### Горячие клавиши
- `Ctrl/Cmd + T` - новая вкладка
- `Ctrl/Cmd + W` - закрыть вкладку
- `Ctrl/Cmd + Tab` - следующая вкладка
- `F5` - обновить

## 📝 Логи ошибок

Если сборка не работает, проверьте:

1. **Node.js версия**
   ```bash
   node --version  # Должно быть v14.0.0 или выше
   ```

2. **npm версия**
   ```bash
   npm --version
   ```

3. **Очистка кеша**
   ```bash
   npm cache clean --force
   ```

4. **Переустановка зависимостей**
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

## 🐛 Решение проблем

### Проблема: "Cannot find module 'electron-builder'"
**Решение:**
```bash
npm install --save-dev electron-builder
```

### Проблема: "Windows Defender/Антивирус блокирует EXE"
**Решение:**
- Это нормально для новых приложений. Подпишите EXE сертификатом или добавьте исключение в антивирус.

### Проблема: "No code signing certificate"
**Решение:**
Для Windows это не требуется. Для macOS вам нужен Apple Developer Certificate.
